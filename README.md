riefly explain the work that you did on this project:

What code were you given? What code did you create yourself?

For this project, I was provided with a preconfigured Jupyter Notebook environment that included the problem framework, supporting libraries, and starter code for building and training reinforcement learning models using Keras. The given code handled environment setup, basic model structure, and evaluation scaffolding. I was responsible for implementing and modifying the learning logic, adjusting model parameters, defining reward behavior, and tuning training settings such as episodes, exploration strategies, and learning rates. Through this process, I gained hands-on experience experimenting with how different configurations impacted agent performance and training stability.

Connect your learning from throughout this course to the larger field of computer science:
What do computer scientists do and why does it matter?

Computer scientists design, analyze, and improve systems that solve real-world problems through computation. This course showed me that computer science is not just about writing code, but about modeling problems, making tradeoffs, and evaluating outcomes. Reinforcement learning, in particular, demonstrates how computer scientists can create systems that adapt and improve over time, which is increasingly important in areas such as automation, optimization, scientific research, and decision-support systems.

How do I approach a problem as a computer scientist?

This course reinforced the importance of breaking complex problems into well-defined components. I learned to identify states, actions, rewards, and constraints, then iteratively test and refine solutions based on observed behavior rather than assumptions. Instead of aiming for a perfect solution upfront, I now approach problems experimentally, using data, feedback, and iteration to guide improvements. This mindset applies broadly across computer science, from software development to AI system design.

What are my ethical responsibilities to the end user and the organization?

My ethical responsibilities include designing systems that are transparent, reliable, and aligned with user intent. Throughout this course, ethical considerations such as bias, unintended behavior, over-automation, and accountability became clear, especially when working with learning systems that can behave unpredictably. As a computer scientist, I have a responsibility to minimize harm, protect user data, clearly communicate system limitations, and ensure that AI systems remain tools that support human decision-making rather than replace it without oversight.
